# Strick-Begleiter

- App type: static, account-free PWA companion to „Dein Strick-Adventskalender zum Mitstricken" (author on KDP: Munich Publishing). Colour edition B0HJ61NCNJ (19,99 €), S/W edition in preparation (Oktober 2026). No backend, no analytics, no e-mail capture; all entries stay in `localStorage` under `strick-begleiter-v1` (done, opened, notes, tab, zaehler).
- Source: `KDP/Meine Bücher/PUBLISHED/Medium Content/Adventskalender-Stricken/Interior/Strick_Adventskalender_FINAL_v5.pdf` (Farb-PDF). `content.js` (window.STRICK_INHALT) is generated by `app_inhalte.py <App-Ordner>` (copy with `app_icon.py` in the book folder `Adventskalender-Stricken/Webapp/`); afterwards content.json is wrapped into content.js: 24 doors verbatim (title, Einleitung, Heute im Blick, Das liegt bereit, Schritte 1–4, Übung, Daran erkennst du das Ergebnis, Wenn etwas hakt, Für heute) plus Rahmenseiten (S. 2 Aufbau, 3 Willkommen, 4 Übungsplatz, 5 Anleitungen lesen, 8 Proben, 129 Abschluss, 130 Spickzettel, 131 Schnelle Hilfe, 132 Quellen). Do not rewrite book copy. Only change: „in Farbfotos gezeigt" → „in Fotos gezeigt" (fits colour and S/W edition).
- Photos: 150 colour photos from the PDF as WebP (max 760 px, q80) in `assets/fotos/` (t01-entdecken, t01-schritt-1/2, t01-detail-1/2, t01-ergebnis …, vorab-*). Captions from the book are alt text and figcaption. The colour photos are the main value for buyers of the S/W edition.
- Navigation: `Heute` (Dezember: Türchen des Tages; vorher Countdown; Fortschrittsring; Weiter mit …), `Türchen` (24 tiles, opened shows result photo, done = check, today highlighted), `Zähler` (Reihen + Maschen, label, optional Wake Lock), `Hilfe` (Schnelle Hilfe + Spickzettel + search over all 48 „Wenn etwas hakt" answers, door chips). Door view `#/tuer/N` with tabs Entdecken / Schritte / Ausprobieren, „Türchen erledigt", note („Mein Zettel"), prev/next. Menu sheet: Vor dem Start links, install guide, backup export/import, Quellen, Abschluss, reset, Impressum/Datenschutz.
- Doors are never locked by date (the book allows any pace; buyers need access before 1 December).
- Assets: `assets/book-cover.jpg` (og:image) and `book-cover-240/480.webp` from the S/W cover front (without „Mit Farbfotos"). Icons rendered with Pillow (`app_icon.py`: plum background, sage yarn ball, wooden needles, gold heart).
- Shell query `v=2` (styles, app; content.js still v=1), service-worker cache `strick-begleiter-v1.1.0`; photos are cached on first view. Shell changes must advance both.
- Christmas design (2026-10-05, Sven: „mach die app weihnachtlicher“): home hero = dark plum card with gentle CSS snow and the book's wreath (`assets/deko/kranz.webp`, cut out from docx image27) showing the countdown to 1 December, in December the door number; garland (`girlande.webp`, image29) under the hero and above the door grid; doors as advent-calendar tiles in red, fir green and plum with gold frame; door number inside the wreath on door pages; mood photos `stimmung-wolle.webp` (Vor dem Start) and `stimmung-schleife.webp` (all 24 done). Plum stays the brand colour (cover, landing page, book mockup).
- Deployment target: `https://tools.munichpublishing.de/strick-advent/` via the central GitHub Pages repo (checkout `Bonus-App/tmp/central-pages-deploy`). Lead magnet: MailerLite landing page, DOI thank-you button links to this URL.
- Local QA 2026-10-04 (in-app browser 375×812): home, grid, door 17 all tabs, lightbox, done + note persisted, counter, help search („Kante" → 3 hits), Vor-dem-Start pages, menu; no console errors.
