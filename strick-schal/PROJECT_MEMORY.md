# Mein Schal (Reihenzähler-App)

- App type: static, account-free PWA companion to the S/W new edition „Dein Strick-Adventskalender: 24 Türchen, ein Schal“ (Munich Publishing, 113 pages, 7×10 in). No backend, no analytics, no e-mail capture. State in `localStorage` under `strick-schal-v1` (pos, done, ends, rid, bow, started, tab).
- URL: `https://tools.munichpublishing.de/strick-schal/`. The QR code on book page 111 points here directly (no landing page in between). Book page 111 says: scan, tap „Mit Türchen 1 anfangen“.
- Data: `data.js` (window.SCHAL) is generated by `export_app.py` from the book build (`build.py`, `plan.py`, `knit.py` simulator, `content.py`). Never edit by hand: 324 rows plus the half row 15 of door 13, per door kniff (steps, captions from the book), schal instructions, Maschen-Check text, expected stitch count (door 11: 27, door 13: 27 after the half row, otherwise 28), riddle hint and solution, Wollwahrheit, help entries.
- Photos: 137 WebP copied from `../strick-advent/assets/fotos/` (old door numbers in the file names, mapping new door → old door in data.js via the photo paths). Door 19 has no photos (as in the book). Captions are the book captions.
- Views: Start (cover, progress, 24 doors), `#/reihe` (row navigator, big „Reihe fertig“, Wake Lock), `#/check/N` (stepper, correct → door done, wrong → help „zu viel“/„zu wenig“ with links to kniffs), `#/tuer/N/(kniff|schal|raetsel)`, `#/hilfe`, `#/anschlagen` (copied from strick-advent, texts patched to 28 stitches), `#/stand`, `#/installieren`, `#/info`.
- Service worker cache prefix `strick-schal-`; only deletes its own caches (same origin as the other apps). Shell changes: bump `?v=` in index.html and the cache name.
- QA 2026-11-03 (Playwright 390×844): all 325 row steps clicked through, 21 checks with expected counts, wrong count path, anschlagen, riddle tab, no console errors.
