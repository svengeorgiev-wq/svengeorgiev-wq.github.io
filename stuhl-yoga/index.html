Ihre Vorführ­videos

Tipp: Videos immer griffbereit

Legen Sie diese Seite auf Ihren Startbildschirm. Dann öffnen Sie die Videos mit einem Fingertipp, so wie eine App, ohne etwas einzutippen.

iPhone / iPad (Safari)

  1. 1Tippen Sie auf das Teilen-Symbol (ein Viereck mit Pfeil nach oben). Sehen Sie es nicht? Dann tippen Sie zuerst auf die drei Punkte • • • und danach auf „Teilen“.
  2. 2Wischen Sie in der Liste nach unten und tippen Sie auf „Zum Home-Bildschirm“.
  3. 3Tippen Sie oben rechts auf „Hinzufügen“.

Android-Handy (Chrome)

  1. 1Tippen Sie oben rechts auf die drei Punkte ⋮.
  2. 2Tippen Sie auf „Zum Startbildschirm hinzufügen“ (bei manchen Handys heißt es „App installieren“).
  3. 3Tippen Sie auf „Hinzufügen“.

Samsung-Handy mit dem Browser „Samsung Internet“? Dann unten rechts auf die drei Striche ≡ tippen, dann „Seite hinzufügen zu“, dann „Startbildschirm“.

Geschafft! Die Videos finden Sie jetzt auf Ihrem Startbildschirm.
