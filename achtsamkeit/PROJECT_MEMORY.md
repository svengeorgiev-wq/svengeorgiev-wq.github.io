# RUHE-Begleiter

- App type: static, account-free PWA companion to „Achtsamkeit & Gelassenheit für normale Leute“ by Sven Georgiev (Munich Publishing; KDP author, cannot be changed. The file name suffix „_Baumann“ is historical, never show Baumann in the app). No backend, no analytics, no e-mail capture; all entries stay in `localStorage` under `ruhe-begleiter-v1`.
- Source manuscript: `29.9.26 Achtsamkeit_Gelassenheit_Baumann.docx` (book folder `KDP/Meine Bücher/PUBLISHED/High Content/Achtsamkeit_Gelassenheit Buch`). `content.js` holds the twelve tools (steps, Minimalversion, „Wenn es hakt“, Kapitel- und Workbook-Verweise), the 21 workbook days, the 24 sources with DOI and the Anhang-B texts, copied verbatim from the manuscript. Do not rewrite tool or day copy.
- Promise printed in the book (page „Dein Zugang zum RUHE-Begleiter“ and Anhang B): all twelve tools as step-by-step guides, a timer for Das lange Ausatmen and Die Fünf-Minuten-Sitzung, the 21-Tage-Übersicht with checkboxes, everything stored on the device only. Module names are fixed to the book's tool titles: Der RUHE-Stopp, Das lange Ausatmen, Das Gedanken-Etikett, Die Fünf-Minuten-Sitzung, Die Übergangsnotiz, Das Check-Fenster, Die ersten drei Bissen, Die Draußen-Runde, Die freundliche Pause, Die Zehn-Sekunden-Antwort, Der Abendabschluss, Der Sonntags-Check.
- Navigation: `Heute`, `21 Tage`, `Werkzeuge`, `Timer`, `Belege`. Header quick button opens Der RUHE-Stopp. Settings sheet = Anhang B (install guide with the book's wording, backup export/import, troubleshooting, help numbers, privacy reset, legal links to munichpublishing.de/impressum and /Datenschutz).
- Guided timers are phase-based and survive reloads (`state.timers[key]` with `startAt` + phases): `breath` (4 in / 6 or 8 out, 5–8 rounds, animated orb), `sitting` (5 or 1 minute, ends with the one-word question), `stopp` (10/15/20/15 s), `outside` (30/60/45/60/45 s), `ten` (10 s), `evening` (4 min). End signal: WebAudio chime plus vibration; the AudioContext is created on the start tap.
- Tool-specific inputs: Gedanken-Etikett chips plus daily tally, Check-Fenster times plus daily Griff counter with 14-day history, drei Bissen checklist per day, freundliche Pause fields with name, Abendabschluss „Für heute ist zu“ per day, Sonntags-Check with history (max 26 weeks).
- Assets: `assets/book-cover-v1.png` is the supplied cover, `book-cover-v1.webp` (480 px) and `book-cover-240.webp` are the in-app versions. Icons are rendered with Pillow (sea-blue gradient, waves, yellow sun, white „RUHE“).
- Shell query is `v=2`; service-worker cache `ruhe-begleiter-v1.0.1` (author fix 2026-09-30). Shell changes must advance both.
- Public deployment target: `https://tools.munichpublishing.de/achtsamkeit/` through the central GitHub Pages repository `svengeorgiev-wq/svengeorgiev-wq.github.io` (checkout `Bonus-App/tmp/central-pages-deploy`). The user asked for this deployment on 2026-09-29.
- The current Amazon listing found on 2026-09-29 (ASIN B0D1GFG2PL, Kindle, April 2024) still shows the older edition with the subtitle „Für Nicht-Esoteriker“; the new edition was not yet visible, so the app carries no Amazon link.
- Local QA on 2026-09-29 (in-app browser, 375×812): all twelve tool sheets render without errors, timers start and persist, day check-off, sources (24) and tool list (12) verified. Service-worker registration is blocked inside the in-app browser; it is verified on the live domain instead.
